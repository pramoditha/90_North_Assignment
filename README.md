Responsive Webpage with Collapsible Menu
This project is a responsive webpage with a fixed navbar, a collapsible left menu, a right-side panel, and a footer. The layout adjusts dynamically based on the screen width, and the page shrinks according to specific conditions. It is built with HTML, CSS, and JavaScript.

Features
Fixed Navbar: A fixed navigation bar that remains at the top when scrolling.
Collapsible Left Menu: A left menu that can be toggled open or closed.
Responsive Layout: The layout adjusts dynamically based on screen width.
Page Scaling: The page shrinks proportionally based on specific screen width conditions.
Right-Side Panel & Footer: A right panel and footer remain in place across all screen sizes.
Installation
To run the project locally, follow these steps:

Prerequisites
A modern web browser (e.g., Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).
A code editor (e.g., Visual Studio Code) is recommended for editing the files.
Steps to Run the Project
Clone the Repository

Open your terminal/command prompt and clone the repository using the following command:


git clone https://github.com/your-username/responsive-webpage.git

Navigate to the Project Folder
Change your directory to the project folder:

cd responsive-webpage

Open the Project in a Web Browser

You can simply open the index.html file in any modern web browser.
Alternatively, you can open the project in a code editor (e.g., Visual Studio Code) and use the built-in live preview feature.

For example:

Open index.html directly by double-clicking it.
Or use Visual Studio Code’s Live Server extension to view the webpage live.
Check Responsiveness

Resize the browser window to see the responsiveness in action. The layout will adjust, and the page will shrink based on the width of the screen as described in the project.

Technologies Used
HTML: For structuring the webpage.
CSS: For styling and making the layout responsive.
JavaScript: For adding interactivity (collapsible menu and dynamic page scaling).
